USE CASE · 01B MODUL SUPER ADMIN & GURU PENGUJI

Use Case Detail · Manajemen Akademik, Kamera Pengawas & Evaluasi

Rincian kasus penggunaan khusus hak akses Super Admin dan Guru Penguji beserta ketergantungan fungsional «include» dan perluasan «extend».

TATA KELOLA ADMIN

Super Admin & Konfigurasi

  • Akses penuh ke seluruh data induk pengguna, guru, peserta didik, rombel, dan mata pelajaran.
  • Menu Profil Admin kini tampil eksplisit di menu kiri selain Settings.

PENGAWASAN GURU

Kamera Guru & Live Grid

  • Guru dapat memeriksa kesiapan kameranya sendiri lewat /guru/camera-check.
  • Kamera pengawas dapat disiarkan selama sesi ujian dan menyimpan foto verifikasi murid.

KETERLACAKAN

Keamanan & Audit Trail

  • Seluruh mutasi kritis otomatis menyertakan guard RBAC, token CSRF, dan pencatatan audit_logs.
  • Guru hanya dapat memantau ujian dan bukti kamera miliknya sendiri.
