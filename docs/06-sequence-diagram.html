U-Line · Full Sequence Diagram (Alur Pertukaran Pesan Realtime)

Interaksi berbasis waktu (*Time-Ordered Message Exchange*) yang mengintegrasikan 5 komponen inti: Klien Browser & WebRTC, Controller MVC, Fonnte WhatsApp Gateway, AI Proctoring (NVIDIA NIM), dan MySQL Persistence Layer.

MEKANISME 2FA & KEAMANAN

Branching ALT: Validasi OTP WhatsApp

  • Brute-Force Guard: Setiap percobaan salah menaikkan kolom attempts; setelah 5 kali gagal berturut-turut, OTP langsung dihanguskan.
  • Idempotency Token: Server mencatat stempel waktu kedaluwarsa mutlak (+5 menit) dan flag is_used=1 untuk mencegah replay attacks.

ASINKRONITAS & DEBOUNCE

Optimasi Autosave Ruang Ujian

  • Buffering 1500ms: Input perubahan jawaban siswa ditampung sementara sebelum dieksekusi melalui Fetch API guna meminimalkan lonjakan query SQL.
  • Fallback Offline: Jika jaringan terputus sementara, jawaban tersimpan di localStorage peramban hingga koneksi pulih kembali.

INFERENSI AI REALTIME

Evaluasi Citra Wajah & Scoring

  • Snapshot Berbobot: Frame dikirim terkompresi base64 ke modul NVIDIA NIM; anomali multi-wajah menambah +15 poin risiko secara kumulatif.
  • Polling Sinkron Pengawas: Dashboard guru melakukan polling agregat setiap 15 detik untuk merefleksikan siswa berisiko tinggi.
