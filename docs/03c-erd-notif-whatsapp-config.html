ERD · 03C CLUSTER NOTIFIKASI, WHATSAPP GATEWAY & KONFIGURASI (TABEL 14–19 / 19)

U-Line · Antrean Notifikasi, Web Push, Fonnte OTP & Pengaturan Global

Skema pengiriman multi-kanal yang terhubung ke entitas referensi users [C1]: inbox aplikasi (notifications), langganan Web Push VAPID (push_subscriptions), autentikasi WhatsApp OTP & audit pengiriman Fonnte (whatsapp_otps, whatsapp_logs), serta dua tabel konfigurasi independen.

NOTIFIKASI & WEB PUSH

Inbox & Langganan VAPID

  • notifications mendukung tautan kontekstual via pasangan polimorfik reference_type + reference_id serta pelacakan status is_read / read_at.
  • push_subscriptions menggunakan endpoint_hash VARCHAR(64) UNIQUE agar pendaftaran perangkat tidak duplikat tanpa membatasi panjang URL endpoint browser.
WHATSAPP GATEWAY & IDEMPOTENCY

Fonnte OTP, Retry & Audit

  • whatsapp_otps membatasi serangan brute-force lewat kolom attempts, status is_used, expires_at, dan asal ip_address.
  • whatsapp_logs menjamin bebas kirim-ganda (exactly-once guard) via idempotency_key UNIQUE dan merekam payload mentah Fonnte serta retry_count.
TABEL KONFIGURASI MANDIRI

Isolasi Parameter Sistem

  • whatsapp_settings menyimpan key-value runtime gateway & template (setting_key UNIQUE) secara terpisah dari token environment sensitif (FONNTE_TOKEN).
  • exam_configs menyimpan pengaturan global rilis token ujian (token, token_secret) serta default pengacakan soal & opsi.
